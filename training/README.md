# Archivio sperimentale

I modelli addestrati da zero per comandi, visione e risposte non sono richiesti dal catalogo Qwen e non sono caricati dal nuovo percorso di Regista. Questi sorgenti restano per consultazione e recupero storico. Checkpoint, pesi e dati dell'utente non vengono cancellati.

La demo comandi è disponibile soltanto nel vecchio backend di rollback (`REGISTA_PHOTO_CATALOG=0`); non fa parte dell'interfaccia nuova o dell'APK protocollo 2. I file Android dei vecchi interpreti sono recuperabili dalla cronologia Git.
